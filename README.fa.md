# OrinOs

[English](README.md) | فارسی

**OrinOs یک توزیع مستقل مبتنی بر Arch Linux است که از Arch Linux به‌عنوان upstream استفاده می‌کند.**

OrinOs یک fork نیست: هر چیزی که در مخازن Arch وجود دارد، بدون تغییر و مستقیماً از Arch مصرف می‌شود. OrinOs فقط بخش‌های خودش را توسعه و نگهداری می‌کند — یک ISO زنده (live)، پیکربندی توزیع، یک نصب‌کننده گرافیکی، مخزن پکیج اختصاصی و برندینگ — در حالی که سیستم‌های نصب‌شده همچنان با `pacman -Syu` از مخازن Arch به‌علاوه مخزن OrinOs به‌روزرسانی می‌شوند.

**وضعیت:** فاز معماری (شروع پروژه). هنوز ISO، نصب‌کننده یا مخزن پکیجی وجود ندارد. سند کامل معماری، وضعیت تصمیم‌ها (DECIDED / PROVISIONAL / TO BE EVALUATED) و نقشه راه در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (به انگلیسی) موجود است.

## ساختار ریپو

```
docs/       مستندات معماری و پروژه
```

دایرکتوری‌های دیگر (`profiles/`، `build/`، `packages/`، `installer/`، `ci/`) همراه با اولین فایل واقعی‌شان، در فاز مربوطه ایجاد می‌شوند.

## نقشه راه

1. تعریف معماری ← فاز فعلی
2. ISO حداقلی
3. تست بوت
4. پیکربندی توزیع
5. برندینگ
6. نصب‌کننده گرافیکی (ارزیابی: archinstall به‌عنوان کتابخانه در برابر Calamares)
7. تست خودکار
8. CI/CD
9. اولین انتشار عمومی
10. نگهداری بلندمدت

## پیش‌نیازها (برای فازهای بعدی)

ساخت ISO به Arch Linux با پکیج `archiso` نیاز دارد؛ تست به `qemu` و `edk2-ovmf` نیاز دارد. دستورالعمل دقیق هر ابزار، همزمان با انجام شدن فاز مربوطه مستند می‌شود.
